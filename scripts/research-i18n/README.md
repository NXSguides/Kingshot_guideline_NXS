# Public research pages — translations (de fr es tr id ru th)

Source of `data/research-i18n.js` (made 2026-11-20). `todo.txt` is the numbered English sentence list; each `<lang>.tsv`
has the same numbers. Numbers missing from a `.tsv` are filled automatically (repeats of an earlier sentence, hero-name-only
lines, codes, and words taken straight from `data/terms.js`). Game terms follow `data/terms.js`.

If a public report's English text changes, the matching line here is out of date: retranslate that line and rebuild
`data/research-i18n.js` (the merge script is not in the repo yet — ask Claude to redo it from the Project doc
`claude/public-research-2026-11-20.md`).
